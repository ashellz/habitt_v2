## Description
*(1175 chars)*

Habittは、ひとつの考えを軸につくられた習慣トラッカーです。あなたのデータは、あなたのもの。
アカウント不要。インターネット不要。解析なし、広告なし。

自分に合った記録方法
習慣ごとに測り方を選べます。回数（水のコップ数、読んだページ数、レップ数）でも、時間（運動の分数、勉強の時間）でも。今の生活に合う目標を決めて、慣れてきたら少しずつ上げていきましょう。

スケジュールは柔軟。習慣があなたのリズムに合わせます。
• 毎日、毎週、毎月、またはカスタム間隔
• 週や月の特定の曜日・日付
• 時間帯で整理：朝、昼、夕方、いつでも

続ける力を支える
Habittはすべての習慣について、現在の継続日数と過去最長の継続日数を記録します。ただし、厳しくはしません。

「習慣の強さ」は最近の継続具合を見て、パーソナルコーチのように働きます。数日抜けてしまったら、目標が高すぎるかもしれないと伝えて、下げることを提案します。順調なら、目標を上げるよう後押しします。「こうあるべき」ではなく、「今のあなた」に合わせます。

進捗が見える
• 習慣ごとのヒートマップと達成カレンダー
• 継続記録の履歴と統計
• 傾向分析つきの強度スコア

リマインダー
どの習慣にも複数の通知を設定できます。必要な時刻と曜日をそのまま指定できるので、もう忘れません。

バックアップ
Habittはすべてを端末内に保存します。クラウドに控えが欲しくなったら、Googleアカウントを接続するだけ。暗号化されたバックアップが、あなた自身のGoogleドライブへ自動で同期されます。データは転送前に端末上でAES-256により暗号化されます。私たちにも、他の誰にも読めません。

すぐに始める
HabitKitなど他の習慣アプリから、習慣をまるごとインポートできます。用意されたテンプレートを使えば数秒で開始できます：早起き、早寝、ジム、ランニング、ウォーキング、水を飲む、歯みがき、スキンケア、食事、勉強、読書、服薬、集中セッションなど。

外観
ダークモードとライトモード。

ひとりの開発者がつくっています
Habittは一人の開発者が開発・運営しています。すべての機能が利用でき、記録できる習慣の数に制限はありません。サブスクリプションは開発の継続を支えています。登録してくださる方一人ひとりが、本当に力になっています。
